# 支撐與壓力位計算說明

**相關檔案：**
- 後端演算法：`backend/app/routers/chart.py` → `_find_sr_levels()`
- 前端繪製：`frontend/src/pages/StockChart.jsx`

---

## 一、核心概念

### 什麼是支撐與壓力？

| 名詞 | 定義 |
|------|------|
| **壓力位（Resistance）** | 股價上漲時容易遇到賣壓而反轉的價格區域，位於**當前價格之上** |
| **支撐位（Support）** | 股價下跌時容易因買盤承接而止跌的價格區域，位於**當前價格之下** |

這些價格區域之所以有意義，是因為市場參與者有記憶——過去曾在某個價格發生過多次反轉，未來遇到同樣價格時，買賣力量仍會集中在該處。

---

## 二、演算法：三個步驟

### 步驟 1：找出擺動高點與擺動低點（Swing High / Swing Low）

遍歷所有 K 棒，對每一根 K 棒 `i`，取其左右各 **20 根** 為比較窗格：

```
窗格範圍：[i - 20, i + 20]（共 41 根 K 棒）
```

**擺動高點（Swing High）條件：**
```
high[i] == max(high[i-20 : i+20])
```
若第 `i` 根的最高價是這 41 根裡最大的，則它是一個局部頂點 → 候選**壓力位**。

**擺動低點（Swing Low）條件：**
```
low[i] == min(low[i-20 : i+20])
```
若第 `i` 根的最低價是這 41 根裡最小的，則它是一個局部底部 → 候選**支撐位**。

> **為什麼選 20 根？**
> 日線圖下，20 根約等於一個交易月。這個窗格足夠大到過濾日內雜訊，又不會因為太大而漏掉中期的反轉點。

---

### 步驟 2：過濾並只保留相對於當前價格的有效水位

- **壓力位**：只保留 `price >= current_price × 0.98`（允許 2% 誤差，避免剛突破的舊壓力被排除）
- **支撐位**：只保留 `price <= current_price × 1.02`

---

### 步驟 3：聚類合併（Clustering）— 消除重複水位

多次擺動高點可能落在非常接近的價格（例如 $182.3、$183.1、$182.8），這代表**同一個壓力區間**，應該合併成一條線。

**聚類規則：**

將所有候選點按價格排序後，逐一判斷：
- 若新點與當前群組的第一個點之間的差距 `≤ 1.5%`，則歸入同一群組
- 否則另開新群組

```
容忍度 tol = 1.5%
條件：(新點 - 群組首點) / 群組首點 ≤ 0.015
```

每個群組輸出：
| 欄位 | 說明 |
|------|------|
| `price` | 群組內所有點的**中位數**價格（取中位數比平均值更能代表中心，不受極值影響） |
| `touches` | 群組內的點數，即該水位被觸碰的次數 |
| `strength` | `min(touches, 5)`，用於控制線條粗細與顏色深淺，最高 5 格 |

最後，依 `touches` 由高到低排序，各取前 **6 個**水位。

---

## 三、輸出結構

後端 API `GET /api/stocks/{ticker}/chart` 回傳：

```json
{
  "sr": {
    "resistance": [
      { "price": 195.40, "touches": 4, "strength": 4 },
      { "price": 188.20, "touches": 2, "strength": 2 }
    ],
    "support": [
      { "price": 172.50, "touches": 5, "strength": 5 },
      { "price": 165.30, "touches": 3, "strength": 3 }
    ]
  }
}
```

壓力位按**價格由低到高**排列（R1 最靠近當前價），支撐位按**價格由高到低**排列（S1 最靠近當前價）。

## 四、前端繪製方式

### 在 K 線圖上畫水平線

使用 `lightweight-charts` 的 `series.createPriceLine()` API，在蠟燭圖序列上疊加水平線：

```js
// 壓力線（紅色）
candle.createPriceLine({
  price: lvl.price,
  color: `rgba(248, 113, 113, ${0.35 + lvl.strength * 0.1})`,  // 越強越深
  lineWidth: lvl.strength >= 3 ? 2 : 1,                         // 越強越粗
  lineStyle: 2,          // 虛線
  axisLabelVisible: true,
  title: `R1  182.50  (4x)`,
});

// 支撐線（綠色）
candle.createPriceLine({
  price: lvl.price,
  color: `rgba(52, 211, 153, ${0.35 + lvl.strength * 0.1})`,
  lineWidth: lvl.strength >= 3 ? 2 : 1,
  lineStyle: 2,
  axisLabelVisible: true,
  title: `S1  165.30  (3x)`,
});
```

### 視覺設計規則

| 屬性 | 壓力位 | 支撐位 |
|------|--------|--------|
| 顏色 | 紅色 `#f87171` | 綠色 `#34d399` |
| 線型 | 虛線 | 虛線 |
| 線粗 | strength ≥ 3 → 2px，否則 1px | 同左 |
| 透明度 | `0.35 + strength × 0.10`（強度越高越不透明）| 同左 |
| 標籤 | `R1 $182.50 (4x)` | `S1 $165.30 (3x)` |

### 摘要卡片

圖表下方的 **S/R Summary** 卡片以文字方式列出所有水位，並顯示：
- 距離當前價格的百分比（例如 `+5.2%`、`-3.1%`）
- 強度點（●●●○○）：最多 5 格，幾格就代表被觸碰幾次（上限 5）

## 五、局限性與注意事項

1. **回看期限制**：演算法僅基於 API 回傳的歷史數據（預設 5 年日線）。窗格大小固定為 20 根，對於波動很小的橫盤股，可能識別的擺動點較少。

2. **非即時**：每次切換期間（1M / 5Y 等）才重新計算，不會隨 tick 更新。

3. **不考慮成交量**：目前的水位強度只看「觸碰次數」，沒有加入成交量加權。成交量大的反轉通常代表更強的支撐/壓力，這是未來可優化的方向。

4. **聚類容忍度 1.5%**：對高價股（如 $2000+）這個比例對應的絕對金額較大，可能把本應分開的兩個水位合併。未來可改為動態容忍度（如 ATR 的 0.5 倍）。

5. **只看收盤前的擺動**：窗格要求 `[i-20, i+20]` 都存在，所以最近 20 根 K 棒不會被識別為新的擺動點（因為右側尚無足夠的未來數據）。
